# Artifacts — the objects of her world

Established 2026-10-21. The catalogue of Yellow Rav3n's weapons,
attire, and gear (GROUND-RULES.md §4 + §6 show-don't-spec). Distinct
from `artworks/` (pictures) and `samples/` (excerpts of larger works):
this folder catalogues the *things*.

One entry per artifact: name · what it is in her story · finished
stills from released work · first public appearance (episode index
link). Show, don't spec: no reference sheets, no turnaround packs, no
construction or generation detail.
