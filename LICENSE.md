# Licensing — the map

Decision adopted by the author, 2026-10-21: a three-layer split.
This file is the map; the layer files carry the terms. When this map
and a layer file disagree, the layer file for that material governs —
and flag the disagreement to the author, do not silently pick one.

## On forks and copies

Forking is a GitHub platform mechanic, not a license. GitHub's terms
let any user view and fork a public repository; nothing in this
package can switch that off, and nothing here tries to. Be clear
about what a fork is and is not:

- **A fork grants no rights.** Forking, cloning, or copying this
  repository grants no right to use, reproduce commercially, adapt,
  or redistribute its Core IP beyond the layer terms above. Any use
  outside those terms is infringement, wherever the copy lives.
- **A fork preserves the evidence.** A fork carries this repository's
  commit history, timestamps, and origin attribution with it. It
  cannot backdate or reassign the record of prior creation, and it
  does not transfer ownership of anything.
- **Enforcement follows use, not copying.** The exposure this
  repository accepts is deliberate: what is published here is finished
  work at web resolution, published under the Kitchen Test
  (`GROUND-RULES.md` §3), and the production recipe — prompts,
  reference packs, masters, unpublished canon — is never in this
  repository to be forked. Misuse is answered with the copyright
  claim, the trademark claim, and platform takedown processes.
