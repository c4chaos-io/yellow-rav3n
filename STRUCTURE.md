# Repo structure — as built

The repo was created 2026-10-21 (ahead of the planned Oct 25
session, at the author's order) and is live at
https://github.com/c4chaos-io/yellow-rav3n — her official site.
(GitHub Pages rendering is the adopted plan in GROUND-RULES §1;
its setup/styling status is an open item below, not asserted
here.) This document describes the structure as it stands; the
full rules are in GROUND-RULES.md.

```
yellow-rav3n/
  README.md          <- calling card: evidence chain on top, genesis at the root
  GROUND-RULES.md    <- what this repo is, what goes in, what never does
                        (ratified at creation 2026-10-21; v1.4 adds the
                        Director's Notes as the second public log)
  CENTAUR.md         <- what a Centaur is in these projects, headed by
                        the Centaur Beer Buddies poster (its first
                        public outing, 2026-10-23); the poster image
                        also sits at the root as
                        centaur-beer-buddies-poster.jpg
  LICENSE.md         <- licensing map: the adopted three-layer split
  LICENSE-ARR.md     <- Layer 1: Core IP, All Rights Reserved
  SHARE-PACK.md      <- Layer 2: CC BY-NC 4.0 designated share material
                        (no artwork designated yet — deliberate)
  LICENSE-MIT.md     <- Layer 3: code, MIT
  IP-AND-TRAINING-NOTICE.md <- over all layers: no training, trademarks
  evidence/
    EVIDENCE-INDEX.md <- dated evidence chain behind the milestone links
  episodes/
    EPISODES.md      <- the documented pointer to every episode:
                        X + YouTube, date, duration, full soundtrack credit
    X-POST-REPOSITORY.md <- the complete dated repository of her X posts,
                        kept up to date as new posts ship
  posts/             <- blog + announcements: dated repo-native posts,
                        newest linked from the README "Latest" section.
                        This repo is A Centaur Production's official channel:
                        if it is not announced here, it is not official
  production-log/    <- numbered production-log entries (prodlog_NNN),
                        published depth. RECORDS: what was made, what
                        changed, what shipped. Public cut of the private
                        Production Evolution Log; no prompts, no
                        unreleased plans
  directors-notes/   <- numbered director's-note entries (dirnote_NNN),
                        published depth, selective by the author's choice.
                        REFLECTS: decisions, lessons, discoveries, and
                        why. Public cut of the private Director's Note
                        Log; a note about unreleased work waits until
                        the work is public
  documents/         <- public documents + PDFs, sanitized editions only
                        (internal sources never commit)
  artworks/          <- finished public artworks: key art, posters,
                        covers, title cards, released stills (web res,
                        stamped; canon refs are kitchen, never here)
  artifacts/         <- catalogue of her in-world objects, one entry
                        each. SHOW, DON'T SPEC: finished stills + story,
                        never reference/turnaround packs
  characters/        <- the cast of the universe, one entry per character,
                        published depth — APPEARANCE GATE: an entry exists
                        only once the character has appeared in an
                        official episode or official trailer; no
                        placeholders, no pre-announcing.
                        First entry: yellow-rav3n.md (EMBER, 2026-10-21)
  samples/           <- lookbook excerpts + storyboards of RELEASED work
                        only, web resolution, metadata stripped, kamon +
                        byline stamped. First resident: the Lookbook
                        Vol. 01 public mood board (2026-10-22)
  story/             <- public story material at publish depth — author's
                        call per file; NOT the arc: no future scripts,
                        twists, or Rift/Prime rules (not yet landed)
```

## Fences (full rules in GROUND-RULES.md)

1. All Rights Reserved core, not the house CC BY 4.0 default.
2. Finished, dated evidence only. No private prompt stack, no raw
   reference packs, no canon that has not been ratified.
3. The repo mirrors the public record (X / YouTube only); it never
   scoops unreleased work. Admission gate for every file: the
   Kitchen Test (GROUND-RULES.md §3).
4. Two logs, two jobs (§11): the Production Log records, the
   Director's Notes reflect; no entry is duplicated across them.
5. The tracked repo item stays OPEN: each session adds to the repo,
   no session closes it.
